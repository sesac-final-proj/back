# PRD - 당근 지역생활 고도화 프로젝트

## 1. 프로젝트 개요

당근의 지역성과 중고거래 데이터를 활용해 사용자의 거래 의사결정을 돕고, 지역생활 정보와 지역상생 기부까지 연결하는 서비스다.

핵심 서비스는 3가지로 구성한다.

- 중고거래 분석: 우리 동네 거래 데이터를 기반으로 적정가격-거래빈도-유사상품 정보 제공
- 갖가지: 공사-단수-날씨 등 지역 생활정보를 수집해 AI로 요약하고 지도에서 제공
- 꿈가지: 거래 및 결제 과정에서 포인트를 적립하고 지역 아동복지시설 기부와 지역상권 소비로 연결

---

## 2. 문제 정의

### 중고거래

판매자는 자신의 상품이 우리 동네에서 얼마나 거래되고, 얼마에 판매해야 적절한지 판단하기 어렵다.

→ 지역 실거래 데이터를 활용해 적정가격과 거래빈도를 제공한다.

### 갖가지

공사-단수-날씨 등 생활정보가 여러 공공기관에 분산되어 있어 사용자가 직접 찾아야 한다.

→ 활동동네 기준으로 필요한 정보만 수집-분류-요약해 제공한다.

### 꿈가지

중고거래에서 발생한 가치가 지역사회로 다시 연결되는 구조가 부족하며, 기부 이후 사용처도 확인하기 어렵다.

→ 거래 포인트를 지역 기부와 소상공인 소비로 연결하고 사용결과까지 공개한다.

---

## 3. 주요 사용자

- 중고상품의 적정 판매가격을 알고 싶은 판매자
- 구매가격이 적절한지 판단하고 싶은 구매자
- 우리 동네 생활정보를 빠르게 확인하고 싶은 사용자
- 거래를 통해 지역사회 기부에 참여하고 싶은 사용자

## 4. 핵심 기능

| 영역 | 주요 기능 |
| --- | --- |
| 회원관리 | 회원가입-로그인, JWT 인증, 활동동네 설정, 사용자 Role 관리 |
| 중고거래 | 유사거래 조회, 적정가격 Range, 거래빈도, 분석근거 제공 |
| 구매자 AI | 가격 적정성 평가, 구매 전 확인사항 및 질문 생성 |

| 꿈가지 | 기부금 설정, 기부처 선택, 포인트 적립, 기부내역 제공 |
| 지역상생 | 기부금 사용결과, 지역 소상공인 집행내역, 지역 환류율 제공 |
| 관리자 | 데이터 수집현황-오류관리, 공지관리, 기부내역 관리 |

## 5. 핵심 기능 Flow

### 중고거래

`상품정보 입력 → 유사거래 검색 → 지역 거래빈도 분석 → 적정가격 산출 → 분석근거 제공`

거래빈도 기준:

- 30건 이상: 많음
- 10~29건: 보통
- 3~9건: 낮음
- 3건 미만: 산정불가

가격은 하나의 값을 예측하기보다 실제 거래 데이터를 기반으로 가격 범위를 제공한다.

예: `52만원 ~ 57만원`

---

### 갖가지

`공공정보 수집 → 행정동 분류 → 중복공지 제거 → LLM 요약 → 지도 표시`

초기 데이터:

- 공사
- 단수
- 날씨

AI 요약 정보:

- 일시
- 위치
- 영향
- 행동요령

---

### 꿈가지

`거래/결제 → 포인트 적립 → 기부금 설정 → 기부처 선택 → 기부 → 사용결과 공개`

적립 예시:

- 일반결제 1%
- 중고거래 0.1%
- 중고거래 5,000원 이상 적용

지역 환류율:

`지역 소상공인 집행금액 ÷ 전체 지원금 × 100`

## 6. MVP 범위

### 1순위

- 회원가입-로그인
- 활동동네 설정
- 지역별 유사거래 조회
- 적정가격 Range
- 거래빈도 분석
- 분석 근거 제공
- 공사-단수-날씨 데이터 수집
- AI 공지 요약
- 지도 시각화
- 기부금 설정 및 기부처 선택
- 기부내역 및 지역상생 현황
- 관리자 데이터 현황 및 오류 조회

### 2순위

- 타 플랫폼 가격 비교
- 구매자 AI 고도화
- 관리자 기부 관리

#### 3순위(후순위 나중 구현)

- 예상 재판매가격

## 7. 핵심 데이터

- User: 사용자-Role-활동지역
- Region: 행정동 코드-좌표
- Product: 상품정보
- Transaction: 지역별 중고거래 데이터
- LocalNotice: 지역생활 공지
- Donation: 기부내역
- Facility: 지원시설
- MerchantSpend: 지역상권 집행내역

---

## 8. 서비스 핵심 가치

본 프로젝트는 단순히 중고거래 기능을 추가하는 것이 아니라,

**지역 데이터를 활용해 거래 의사결정을 돕고 → 지역생활 정보를 제공하며 → 거래에서 발생한 가치를 다시 지역사회로 연결하는 구조**

를 만드는 것을 목표로 한다.
